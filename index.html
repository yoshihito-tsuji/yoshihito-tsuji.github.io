Research

研究

My work sits between software engineering and the quantitative modeling of human explanatory behaviour. I design, implement and distribute the applications that my studies run on, and I use the behavioural data they collect to build and test computational models of how speakers adapt an explanation to a listener.

Three strands run through the group:

  • Application development and distribution. On-device speech recognition, data-visualisation tools and browser-based simulators, released on public app stores and maintained as production software.
  • Cognitive modeling of explanatory dialogue. A measurement instrument for a speaker's awareness of the listener, and quantitative validation of the model against behavioural data collected in controlled settings.
  • Generative AI in application development. Human–AI collaborative software construction, including the multi-agent development workflow used to build the tools listed below.

ソフトウェアの設計・実装と、人間の説明行動の定量的モデル化の境界を研究領域としています。 研究に用いるアプリケーションは自ら設計・実装して配布し、そこで得られる行動データを用いて、 話し手が聞き手に応じて説明をどう調整するかの計算モデルを構築・検証しています。

研究の柱は次の3つです。

  • アプリケーションの開発と配布。 端末内で完結する音声認識、データ可視化ツール、ブラウザ上で動作するシミュレータを、 公開ストアでリリースし、実運用のソフトウェアとして保守しています。
  • 説明対話の認知モデル化。 話し手の受け手意識を測定する尺度の構成と、統制された条件下で取得した行動データによる モデルの定量的検証を行っています。
  • 生成AIを用いたアプリケーション開発。 人間とAIの協働によるソフトウェア構築。下記のツール群も、この多エージェント開発フローで 作られています。

Software

ソフトウェア

GaQ Offline Transcriber

A fully offline speech-to-text application for Windows and macOS. All recognition runs on the local device; no audio leaves the machine. Built for research interviews and classroom recordings where the data cannot be sent to a cloud service.

Windows / macOS 向けの完全オフライン文字起こしアプリケーション。 音声認識はすべて端末内で完結し、音声データは外部に送信されません。 クラウドに送れない研究面接や授業記録での利用を想定しています。

Microsoft Store Privacy policy

PoPuP

A population-pyramid construction tool for iOS, macOS and Windows, used for teaching demographic data literacy.

iOS / macOS / Windows 向けの人口ピラミッド作成ツール。 人口統計データのリテラシー教育で使用しています。

App Store Releases Support

Monty Hall Simulator

A single-file, dependency-free browser simulator of the Monty Hall problem, localised into 12 languages. Used to make conditional probability tractable by direct experiment rather than derivation.

モンティホール問題を体験できる、単一 HTML・依存関係なしの シミュレータ（12言語対応）。条件付き確率を、導出ではなく実際に試すことで つかめるようにしたものです。

Live demo Source

SPChart

A tool that builds S–P (Student–Problem) charts automatically, supporting item analysis of classroom tests. Developed through a human–AI collaborative workflow.

S-P 表を自動生成し、テストの項目分析を支援するツール。 生成AIとの協働開発フローで作成しています。
